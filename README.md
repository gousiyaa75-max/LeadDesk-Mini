# LeadDesk Mini 🚀

LeadDesk Mini is a Django-based Lead Management System that helps businesses capture and manage leads through a modern responsive interface.

## 🌐 Live Demo

🔗 Live Website:
https://leaddesk-mini-2-kmq8.onrender.com

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## ✨ Features

- Lead submission form
- Admin panel for managing leads
- Responsive landing page
- Secure Django form handling
- Modern UI design
